# CV Angola
Gerador de Curriculum Vitae (HTML + CSS + JS puro). Sem backend, sem login. Dados em localStorage.
## Publicar no GitLab Pages
1. Crie um projecto no GitLab e envie estes ficheiros (branch principal).
2. O `.gitlab-ci.yml` publica automaticamente. URL: Deploy > Pages.
## Pagamento
Dados de pagamento em `js/app.js` (constante `PAY`). O desbloqueio é feito no frontend (pode ser contornado) - versão de teste de mercado.
Futuro: backend para confirmar pagamentos, códigos e contas.
